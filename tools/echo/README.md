# Echo 双端通信测试工具

独立的通信链路验证工具（与主档案服务相互独立，端口 8701/8702）。

## 链路

```
浏览器 → Echo 客户端服务 :8702 → Echo 服务端 :8701
```

| 端 | 地址 | 界面 | 职责 |
|----|------|------|------|
| 服务端 | http://127.0.0.1:8701 | `/`（打开即界面） | 接收数据 → 按模式处理 → 返回结构化结果；维护请求台账 |
| 客户端 | http://127.0.0.1:8702 | `/`（打开即界面） | 发送界面：输入数据/选模式/发送；展示返回结果、状态与耗时 |

## 使用

双击 `start.bat`（分别启动两个窗口），或手动：

```bash
python tools/echo/echo_server.py   # 窗口 1
python tools/echo/echo_client.py   # 窗口 2
```

## 验证要点

1. 客户端界面顶部的链路状态灯：绿色「链路正常」= 两端通信正常；
2. 发送数据 → 状态条变为「发送中…」→ 成功后显示绿色确认 + 往返耗时/服务端处理耗时；
3. 服务端界面请求台账 2 秒内自动出现对应记录（含 ID/模式/原始数据/结果/耗时）；
4. 处理模式：echo 原文回显 / upper 转大写 / reverse 反转 / stats 统计（MD5 等）；
5. 关掉服务端窗口后客户端发送 → 应看到红色失败提示（验证异常反馈），重启后自动恢复。
